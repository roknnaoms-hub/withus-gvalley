# 위더스행정사 · G밸리 기업행정 웹사이트

서울디지털국가산업단지와 지식산업센터의 입주·운영·이전 관련 절차를 안내하는 정적 웹사이트입니다. 별도 서버, 외부 CDN, API 키, 유료 서비스가 필요하지 않습니다.

## 구성

- 전문 업무 6개 분야
- 행정사 4인: 황인동, 정기택, 신창환, 오명섭
- 주요 행정절차 13개, 자가·임차별 준비서류 조회
- 준비서류 체크리스트 TXT 내려받기, 인쇄/PDF
- 모바일 메뉴와 전화 연결, 이메일 초안 작성, 상담 내용 복사
- 한국산업단지공단·팩토리온·대한행정사회·관련 법령 등 자료 링크

## 자료 기준

1. 사용자가 제공한 「기업행정 브로슈어-240513-1.PDF」: 업무, 4인 이름과 소속 표기, 사무소 연락처.
2. 사용자가 제공한 한국산업단지공단 「서울디지털국가산업단지 입주절차 안내」: 실제 본문 발간일 2023년 10월. 준비서류 요약은 본문 45~54쪽에 근거합니다. 파일명에 붙은 2026년 날짜는 발간일로 사용하지 않았습니다.
3. 공단 공식 안내 https://www.kicox.or.kr/contents/34
4. 구로구청 입주절차 https://www.guro.go.kr/www/contents.do?key=2851
5. 제공된 네이버 링크는 서울지역 입주안내 블로그(kicoxs12), 창업행정 참고 글(gongmu24/224005225511)로 연결됨을 확인했습니다. 블로그 본문 전체와 최신 첨부서식은 확인·복제하지 않았으며, 타 사무소의 경력·실적을 사용하지 않았습니다.

웹자료 확인일: 2026-10-18. 이 확인일은 모든 법령·관리기본계획 변경을 전수 검증했다는 뜻이 아닙니다. 절차별 출처와 최신 적용 여부 확인 안내를 화면에 표시합니다. 새 서식은 공식 사이트에서 확인하며, 과거 서식을 최신 서식처럼 재배포하지 않습니다.

## 운영·유지관리

- `index.html`: 사무소 소개·업무·4인 구성·연락처·자료 링크
- `app.js`: `PROCEDURES` 배열의 13개 절차 및 자가·임차별 준비서류
- `style.css`: 반응형 화면·인쇄 양식
- `favicon.svg`: 사이트 아이콘
- `.nojekyll`: GitHub Pages 정적 파일 제공

변경 후 `node --check app.js`로 문법을 점검합니다. GitHub Pages에서 `main` 브랜치 루트(`/`)를 게시하도록 설정합니다. `index.html`을 직접 열어도 기본 안내와 체크리스트는 동작합니다. 이메일 작성은 사용자 기기의 메일 앱 설정에 따라 달라집니다.

이 사이트는 개인정보 입력을 서버에 저장하거나 상담을 자동 접수하지 않습니다. 메일 앱의 최종 발송은 방문자가 수행합니다. 사이트 자체 분석도구·추적 쿠키·유료 API 호출은 없습니다. GitHub Pages 호스팅 및 사용자가 이동하는 외부 사이트에는 각 서비스 정책이 적용됩니다.

모든 인허가·인증·등록의 최종 결정은 해당 기관이 하며, 다른 전문자격 업무는 해당 자격사의 업무 범위를 구분하여 안내합니다. 공단 공식 사이트로 오인되지 않도록 민간 행정사사무소 안내임을 표시합니다.
